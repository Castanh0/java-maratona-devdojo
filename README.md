# ☕ Estudos Java — DevDojo

Repositório criado para registrar minha jornada de estudos em **Java**, acompanhando as aulas da **Maratona Java Virado no Jiraya**, do [DevDojo](https://devdojo.com.br/).

Criei este espaço no GitHub exclusivamente para meus estudos, utilizando o repositório para armazenar os códigos, exercícios, desafios e projetos desenvolvidos durante minha evolução na linguagem.

---

## 🎯 Objetivo

O principal objetivo deste repositório é construir uma **base sólida em Java**, praticando os conceitos apresentados nas aulas e acompanhando minha evolução ao longo do curso.

Além de assistir às aulas, procuro colocar os conhecimentos em prática através de exercícios e pequenos projetos.
